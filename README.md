## ▶️ How to Run a Program

1. Clone the repository:

```
git clone https://github.com/your-username/your-repo-name.git
```

2. Navigate to the folder:

```
cd your-repo-name
```

3. Compile the program:

```
gcc filename.c -o output
```

4. Run the program:

```
./output
```
